# What's Interesting — Telegram Mini App

Статическое меню персонального Telegram-бота: четыре крупные плитки с независимыми цветами — погода, политика, ИИ, интересное. Без GIF, аналитики, серверного кода и секретов.

Открывается через `KeyboardButton.web_app` в личном чате с ботом. Выбор передаётся методом `Telegram.WebApp.sendData` как JSON `{ "v": 1, "section": "weather|politics|ai|other" }`. Telegram доставляет его локальному боту в `Message.web_app_data`; сам бот проверяет отправителя, доступ и очередь. Подлинность пользователя определяется полем `from` обновления Telegram, а не содержимым страницы.

При прямом открытии в обычном браузере страница показывает меню, но не отправляет задания. Внешний ресурс — только официальный SDK Telegram. Токены Telegram/OpenAI и авторизация ChatGPT здесь отсутствуют.

GitHub Pages публикует `main` → корень `/`, `.nojekyll` отключает обработку Jekyll. Обновление `index.html` и push в main запускает публикацию. Домен maxaicraft.ru не меняется.
